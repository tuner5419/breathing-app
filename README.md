#  4-4-6 Breathing Exercise App

A guided breathing exercise web app that runs on any device - iPhone, Android, desktop, and more. No installation needed, completely private, works offline.

##  Features

- **4-second breathe in** (through nose)
- **4-second hold** (breath retention)
- **6-second breathe out** (exhale)
- **10 automatic cycles** (~2 minutes 20 seconds total)
- **Works on all devices**: iPhone, Android, Windows, Mac, Linux
- **Completely offline** - no internet required after loading
- **Privacy first** - no data collection, no tracking
- **Beautiful UI** - responsive design, color-coded phases
- **No installation** - just open the link

##  Quick Start

### Use Online
Simply visit: **https://tuner5419.github.io/breathing-app**

Then:
1. Click **"Start Exercise"**
2. Follow the colored circle
3. Breathe naturally with the guidance
4. Complete 10 cycles (~2:20 minutes)

### Add to Home Screen (Quick Access)

**iPhone:**
1. Open the link in Safari
2. Tap Share button (bottom)
3. Tap "Add to Home Screen"
4. Name it "Breathing"

**Android:**
1. Open the link in Chrome
2. Tap menu (⋮)
3. Tap "Install app"

Now you have an app icon on your home screen!

##  The Breathing Pattern

Each cycle: **14 seconds**

| Phase | Duration | Color |
|-------|----------|-------|
| Breathe In | 4s | 🔵 Blue |
| Hold | 4s | 🟡 Yellow |
| Breathe Out | 6s | 🟢 Green |

**Total:** 10 cycles = ~2:20 minutes
